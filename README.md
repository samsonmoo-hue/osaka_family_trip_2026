# Osaka Family Trip 2026

Static one-page itinerary for a five-person Osaka family trip from 2026-07-21 to 2026-07-25.

## GitHub Pages

This repository is ready for GitHub Pages.

Recommended publishing options:

1. Settings -> Pages -> Source: GitHub Actions
2. Run the included `Deploy static site to GitHub Pages` workflow

If you prefer branch publishing, use:

1. Settings -> Pages
2. Source: Deploy from a branch
3. Branch: `main`
4. Folder: `/ (root)`

https://samsonmoo-hue.github.io/osaka_family_trip_2026/
