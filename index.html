Plan Logic

行程原則

少拉車

每天集中同一區，降低轉乘與步行壓力，適合70歲長輩同行。

生活感

保留天神橋筋商店街、玉出超市、晚間水果甜點採買。

保留海遊館

看鯨鯊與搭摩天輪，刪掉搭船與附屬景點，時間更乾淨。

和牛之夜

利用公寓式住宿廚房，一晚採買黑毛和牛、水果與沙拉回房間料理。

住宿 住一道頓堀2號店

島之內／日本橋／道頓堀步行圈，適合作為每天回飯店休息與採買基地。

交通 ICOCA + Osaka Metro + 南海電鐵

不買 JR Pass 或大阪周遊卡。機場搭南海電鐵至天下茶屋轉堺筋線；市區交通刷 ICOCA，景點採單點門票。

最後一天 班機很晚，保留彈性

可走難波八阪神社、心齋橋與難波最後採買；體力足夠再加臨空城。

每日行程

Day 1 · 7/21 Tue

抵達大阪，道頓堀遊船與公寓和牛晚餐

今日實際紀錄
今天沒有去黑門市場；改成明天 Day 2 去完大阪城之後再去。今晚保留道頓堀遊船、串炸、超市採買和牛與回公寓料理的紀錄。
12:30

抵達關西機場

入境後搭南海電鐵到天下茶屋，站內轉 Osaka Metro 堺筋線到日本橋。行李先寄放，輕裝開始第一天。

KIX → 南海電鐵 → 天下茶屋 → Osaka Metro 堺筋線 → 日本橋

16:00

入住與道頓堀周邊散步

先放行李、補水休息，再從住宿步行到道頓堀河畔，準備搭遊船看河岸街景。

17:30

道頓堀 River Cruise

搭船從水面看道頓堀、戎橋與兩岸招牌，傍晚光線適合先拍全家合照。

19:00

道頓堀夜景與串炸

在河岸拍夜景與合照，晚餐改吃串炸，節奏比排大型餐廳更輕鬆。

20:30

超市採買黑毛和牛

買到鹿兒島黑毛和牛與配菜，回公寓用廚房料理，補上這趟很有生活感的一餐。

21:15

回公寓料理與宵夜

小孩一起下廚煎肉，搭配麵、飲料或水果收尾。今天就不再排黑門市場，保留體力給明天大阪城。

從道頓堀遊船、河岸夜景到串炸與公寓和牛晚餐，八張照片都放在今天行程中。

Day 2 · 7/22 Wed

大阪城、黑門市場與難波彈性晚餐

黑門順延
黑門市場從 Day 1 順延到 Day 2：上午大阪城，結束後回日本橋／難波吃黑門市場。下午保留休息，晚餐視體力簡單安排。
08:30

飯店附近早餐

便利商店飯糰、咖啡、麵包即可。夏天不要一早就吃太重。

09:30

大阪城公園

主攻天守閣外觀、護城河與拍照。若天氣太熱，天守閣登樓可視現場體力決定。

長堀橋 → 大阪 Metro 長堀鶴見綠地線 → 森之宮

12:00

移動到黑門市場午餐

大阪城結束後回日本橋／難波，去黑門市場補 Day 1 沒吃到的海鮮、玉子燒、現切水果或壽司。

森之宮 / 谷町四丁目 → Osaka Metro → 日本橋 → 黑門市場

14:00

回飯店休息

黑門市場吃完後不要硬逛，先回住宿午休、洗澡與整理照片，避開下午最熱的時段。

16:30

難波或日本橋彈性小逛

Loft、Bic Camera、高島屋、日本橋電電城都可作為短程選項；若大家累了，這段直接取消。

18:30

難波晚餐

依黑門市場午餐份量決定：簡單拉麵、定食、燒肉或回飯店吃水果甜點都可以。

飯店 → 大阪城公園

長堀橋站搭長堀鶴見綠地線到森之宮站，步行進大阪城公園；主攻外觀、護城河與拍照。

大阪城 Google Map 下一站：森之宮或谷町四丁目搭 Metro 回日本橋，接黑門市場。

大阪城 → 黑門市場 → 飯店休息

黑門市場接在大阪城後面，不放在 Day 1。午餐以現吃為主，水果只買當天能吃完的量。

黑門市場 日本橋站 下一站：步行回飯店午休，晚餐再看體力。

Day 3 · 7/23 Thu

海遊館、天保山摩天輪、日本橋動漫採購

海洋與動漫
09:00

前往海遊館

日本橋站搭千日前線到阿波座，轉中央線到大阪港站，步行到海遊館。

日本橋 → 阿波座 → 大阪港 → 海遊館

09:45

海遊館看鯨鯊

預留約3小時。全程室內，這天是最適合夏天避暑的主景點。

12:45

天保山市場午餐

壽司、定食、輕食皆可。不要安排聖瑪麗亞號觀光船，也不排 LEGOLAND。

14:00

天保山大摩天輪

一圈約15分鐘，重點看大阪灣與港口，不需要在天保山逛太久。

16:00

日本橋動漫正式採購

Animate 買新品，駿河屋與 Mandarake 挖二手公仔，Joshin 看模型與玩具。小孩想逛久，長輩可先回飯店休息。

19:00

道頓堀晚餐

串炸、燒肉、壽司或拉麵。回飯店前只補水果與甜點，不買生食。

飯店 → 海遊館

日本橋站搭千日前線到阿波座，轉中央線到大阪港站，步行約5分鐘到海遊館。

海遊館 Google Map 下一站：步行到天保山市場與摩天輪。

天保山市場 → 天保山大摩天輪

午餐後直接步行到摩天輪；不安排聖瑪麗亞號觀光船，也不排 LEGOLAND。

天保山市場 摩天輪 下一站：大阪港站搭中央線到阿波座，轉千日前線回日本橋。

日本橋動漫採購

Animate 買新品，駿河屋與 Mandarake 挖二手公仔，Joshin 看模型與玩具。

Animate 駿河屋 Mandarake 下一站：步行到道頓堀晚餐，或讓長輩先回飯店休息。

Day 4 · 7/24 Fri

天神橋筋商店街、梅田、利久牛舌與 HARUKAS 300

生活感主日
09:30

大阪天滿宮

以短暫參觀與拍照為主，接著直接走進天神橋筋商店街。

日本橋 → Osaka Metro 堺筋線 → 南森町

10:15

天神橋筋商店街慢逛

中村屋可樂餅、前田豆腐店、玉出超市、天滿市場。這天取代木津市場，主打大阪在地生活感。

12:30

大起水產午餐

回轉壽司適合五人，選擇多、翻桌快。若人太多，就改附近定食或拉麵。

15:00

梅田購物與補貨

Grand Front、Yodobashi Camera、Animate 梅田。若 Day 3 動漫還沒買夠，這裡補最後一輪；16:30 左右前往天王寺。

南森町 / 扇町 / 天滿 → 梅田區

17:00

利久牛舌晚餐（HARUKAS 12F）

暫定仙臺たんや利久。五人建議電話預約 17:00；晚餐控制一小時，直接在同棟接 HARUKAS 300。

18:30

阿倍野 HARUKAS 300 夜景

晚餐後直接上展望台，從傍晚待到天黑。建議先買電子票，室內冷氣對長輩較友善。

梅田 → Osaka Metro 御堂筋線 → 天王寺；HARUKAS 與天王寺站相連

飯店 → 大阪天滿宮 → 天神橋筋商店街

日本橋搭堺筋線到南森町，從大阪天滿宮開始，接天神橋筋商店街、中村屋、前田豆腐、玉出與天滿市場。

大阪天滿宮 天神橋筋 中村屋 下一站：商店街午餐後從南森町、扇町或天滿站轉往梅田。

梅田 → 利久牛舌 → 阿倍野 HARUKAS 300

梅田購物後搭御堂筋線至天王寺；利久在 HARUKAS 12F，晚餐後直接前往 HARUKAS 300 看夜景。

Grand Front 利久電話訂位 HARUKAS 下一站：天王寺搭御堂筋線回難波，再步行回飯店。

Day 5 · 7/25 Sat

難波八阪神社、心齋橋最後購物、前往機場

23:35 晚班機
退房後先確認飯店可否寄放行李；不行就放難波站置物櫃。最後一天不買生肉，也不要把水果、肉類帶回台灣。
09:30

難波八阪神社

巨型獅子頭拍照，停留20-30分鐘即可。夏天早一點去比較舒服。

10:30

心齋橋與難波最後採買

藥妝、UNIQLO、GU、Loft、Bic Camera、唐吉訶德。伴手禮以常溫零食為主。

12:30

午餐與最後補貨

若還想吃桃子、葡萄、哈密瓜，可在難波或心齋橋附近買當天吃得完的量；不要買需要帶回台灣的生鮮。

16:00

彈性選擇：臨空城或市區休息

體力好就到 Rinku Premium Outlets；若大家累了，留在難波吃晚餐後直接去機場。

20:30

抵達關西機場

23:35 起飛，20:30 左右到機場很充裕。廉航行李與登機時間請以航空公司通知為準。

南海難波 → 關西機場；若去臨空城，臨空城 → KIX 一站

飯店 → 難波八阪神社 → 心齋橋 / 難波

退房後先寄放行李。難波八阪拍照約20-30分鐘，再回心齋橋與難波做最後採買與午餐。

難波八阪 心齋橋 下一站：依體力決定留市區休息或前往臨空城。

難波 / 臨空城 → 關西機場

23:35 起飛，20:30 左右抵達 KIX 很充裕。若去臨空城，從臨空城站到機場只要一站。

臨空城 關西機場 下一站：南海難波搭南海電鐵到 KIX；或臨空城到 KIX 一站。
